# astrbot_plugin_prompt_cards 提示词卡

把多套提示词（System Prompt 片段）存成「卡片」，在每次 LLM 请求前自动拼接到
system prompt。相当于给 AstrBot 人格系统加了一层可切换、可触发的叠加层：

- **按会话切换**：不同群/私聊可以启用不同的卡，互不影响；
- **关键词触发**：卡片绑定触发关键词后，聊天命中即在当前会话自动启用，
  N 条消息后自动失效——世界书式的条件注入，不用每次手动粘贴；
- **可调试**：`/卡 peek` 随时预览当前会话实际注入了什么。

> 定位说明：本插件只做**提示词的管理与注入机制**，卡内容由使用者自行维护
> （人格设定、语气文风、格式要求等常规提示词）。插件本身不内置、也不针对
> 绕过模型安全策略的内容；提示词的实际效果由底层模型决定。

## 安装

1. 把整个 `astrbot_plugin_prompt_cards` 文件夹放进 AstrBot 的 `data/plugins/` 目录；
2. WebUI → 插件管理 → 重载/启用；
3. 需要 AstrBot v3.4.5+（用到 `on_llm_request` 钩子）。

无第三方依赖。

## 命令

前缀 `/` 可省略，子命令与参数之间用空格。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `/卡 help` | 查看帮助 | 所有人 |
| `/卡 list` | 列出所有卡片、优先级、关键词、本会话状态 | 所有人 |
| `/卡 show <名字>` | 查看卡片内容 | 所有人 |
| `/卡 peek` | 预览当前会话实际注入的提示词 | 所有人 |
| `/卡 预设` | 查看内置预设模板（人格/语气/回答策略） | 所有人 |
| `/卡 on <名字>` | 在当前会话启用卡片 | 所有人 |
| `/卡 off <名字>` | 在当前会话停用卡片 | 所有人 |
| `/卡 clear` | 停用当前会话的全部卡片 | 所有人 |
| `/卡 add <名字> <内容>` | 新建卡片（内容可换行） | 管理员 |
| `/卡 导入 <预设名>` | 从内置预设库导入一张卡（`导入 全部` 全要） | 管理员 |
| `/卡 set <名字> <新内容>` | 修改卡片内容 | 管理员 |
| `/卡 kw <名字> <词1,词2>` | 设置触发关键词（`re:` 前缀按正则匹配；留空清除） | 管理员 |
| `/卡 pri <名字> <数字>` | 设置优先级，数字小的先注入 | 管理员 |
| `/卡 全局 on\|off <名字>` | 全局卡：对所有会话默认生效，不必逐群 `/卡 on` | 管理员 |
| `/卡 del <名字>` | 删除卡片 | 管理员 |

管理员判定优先用 `event.is_admin()`，不可用时回退到面板里的 `admin_ids` 名单。

## 快速上手

```
/卡 预设                 ← 看内置的 11 张模板（毒舌损友、文言文腔调、代码导师……）
/卡 导入 全部            ← 一键全部入卡，之后 /卡 set 随便改写成你要的样子
/卡 on 文言文腔调        ← 本会话立即生效
/卡 kw 文言文腔调 古风,文言
                        ← 之后聊天里出现「古风/文言」的群会自动启用，30 条消息后自动失效
/卡 peek                ← 看看实际注入了什么
```

内置预设只覆盖人格/语气/回答策略这类常规用法，直接手写 `/卡 add` 也完全可以。

## 进阶用法

**变量插值**：卡片内容里可以写 `{user}`（发送者昵称）、`{time}`、`{date}`、
`{weekday}`，每次注入时自动替换成当前值。例如预设「时间感知」就是靠它实现的。

**正则关键词**：`/卡 kw 名字 re:(早|晚上)好` —— `re:` 前缀后面按正则匹配，
适合同义表达多、想一条写完的场景；正则写错只影响这一条，不会拖垮插件。

**全局卡**：`/卡 全局 on 简洁模式` 后该卡在所有会话默认生效，不用每个群都
`/卡 on` 一遍；`/卡 全局 off` 恢复手动模式。适合管理员给整个 bot 定基调。

**长对话锚点**：角色扮演聊得越久人格越容易漂，面板开启「长对话锚点」后，
每次请求会在最后一条用户消息前插入一句可自定义的提醒，把人设拉回来。
对话普遍很短（<20 轮）就不用开，省 token。

**注入字数告警**：面板设置 `max_inject_chars` 后，`/卡 peek` 会在生效卡片
总字数超限时警告（只提醒不截断），避免卡片堆太多把上下文挤爆。

## 与 AstrBot 人格的关系

卡片内容拼接在**现有人格 system prompt 之上**（默认追加在后，可在面板改为
前置），两者同时生效。想整体换人格建议用 AstrBot 自带的人格功能；卡片适合
做局部叠加——语气、文风、格式要求、场景状态这类可组合的片段。

## 配置项（WebUI）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 卡片之间的拼接分隔符 | `\n\n` | 多张卡片注入时的连接文本 |
| 注入位置 | append | append=在人格提示词后追加；prepend=插在其前 |
| 长对话锚点 | 关 | 超长对话人格漂移时开启；锚点文本可自定义 |
| 注入字数上限告警 | 0 | 生效卡片总字数超过该值时 peek 警告，0=不检查 |
| 关键词自动激活 | 开 | 关闭后关键词不再触发，只能手动 `/卡 on` |
| 关键词卡自动失效条数 | 30 | 关键词激活的卡在 N 条消息后自动停用，0=永不失效 |
| 关键词命中提示 | 关 | 命中时发一条提示，调试触发规则时打开 |
| 仅管理员可增删改 | 开 | 关闭则所有人都能管理卡片 |
| 管理员 ID 备用名单 | 空 | 逗号分隔 |

## 数据

卡片与会话启用状态保存在 `data/config/astrbot_plugin_prompt_cards.json`，
可直接编辑（注意 JSON 格式），删除后重启会重新生成两张示例卡。

## 常见问题

**开了卡但模型行为没变？**
先 `/卡 peek` 确认内容真的注入了。确认注入后仍无效果，一般是内容写得太弱
或与人格提示词冲突——人格提示词在后（append 模式）优先级更高，可试试把注入
位置改成 prepend。

**关键词总是误触发？**
把关键词写得具体些（用词组而不是单字），或调小失效条数；调试时打开
「关键词命中提示」观察命中情况。

**不同群想用不同人格？**
卡片按会话（群）独立启用，各自 `/卡 on` 需要的卡即可；`/卡 clear` 清空本会话。
