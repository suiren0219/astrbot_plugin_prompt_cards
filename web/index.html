// Edit 编辑卡片
保守=贴紧设定少发挥；标准=跟随卡片设定；激进=大胆即兴、主动推动剧情。该卡生效时注入对应引导。
感性=情绪浓、感官与心理描写多；理性=克制精确、先结论后感受。
AstrBot 插件 API 暂不支持按会话下发温度；全局调温请在提供商 custom_extra_body 设置。
完全人设=注入时声明压过基础人格（整体换角色）；叠加=在基础人格上做语气/规则微调。
